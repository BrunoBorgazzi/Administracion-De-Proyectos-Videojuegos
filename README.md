## 📌 Sobre este proyecto

Este repositorio contiene el código fuente de una presentación web interactiva diseñada para la asignatura de Administración de Proyectos. Su objetivo es exponer de manera dinámica y moderna los conceptos teóricos y prácticos de la gestión de proyectos en la industria de los videojuegos, con un enfoque particular en el desarrollo *indie* en Argentina.

La presentación abarca:
1. **Teoría de Gestión:** Diferencias entre evaluación ex-ante, durante y ex-post; criterios de viabilidad y metodologías ágiles (Scrum) vs. tradicionales (PMI).
2. **Práctica Aplicada:** Planificación de un videojuego ficticio (*Chrono-Thief*), incluyendo cronogramas de hitos, estimación de presupuestos y una matriz completa de evaluación de riesgos.
3. **Reflexión Crítica:** El rol vital de la administración para la supervivencia de los estudios independientes en el contexto económico argentino, y cómo adaptar estas estructuras para proyectos de escala global (AAA).

## 🛠️ Tecnologías Utilizadas

La página fue construida desde cero priorizando el rendimiento, la estética institucional y el diseño *responsive* sin depender de librerías pesadas:

*   **HTML5 Semántico:** Estructura de diapositivas limpias y accesibles.
*   **CSS3 (Vanilla):** Diseño adaptable (*Mobile First* optimizado), paleta de colores institucionales (Bordó/Dorado UAI), efectos de gradientes radiales sutiles y animaciones personalizadas.
*   **JavaScript (Vanilla):** Lógica del carrusel de diapositivas, manejo de eventos de teclado (flechas), *scroll* y soporte táctil para dispositivos móviles.

## 🚀 Cómo visualizar la presentación

Puedes ver la presentación online a través de GitHub Pages (si está habilitado en este repositorio), o de forma local siguiendo estos pasos:

1. Clona este repositorio:
   ```bash
   git clone https://github.com/BrunoBorgazzi/Administracion-De-Proyectos-Videojuegos.git
   ```
2. Abre el archivo `index.html` en cualquier navegador web moderno.
3. Navega usando la rueda del ratón, las flechas del teclado, o la barra de navegación lateral.
